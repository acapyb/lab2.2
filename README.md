# Lab Exercise 2.2: HTML Table and Form

## Introduction

This repository contains my work for **Lab Exercise 2.2: Table and Form**, which focuses on learning and implementing HTML tables, forms, and basic webpage navigation.

The exercise is divided into four parts: Part A, Part B, Part C, and Part D.

## Objectives

- Understand how to create and structure HTML tables.
- Learn how to use table headers, captions, colspan, and rowspan.
- Create webpage layouts using HTML tables.
- Develop HTML forms using different input elements.
- Build multiple HTML pages and connect them using navigation links.
- Practice using Git and GitHub for version control.

## Lab Activities

### Part A: HTML Tables

This section demonstrates five HTML table examples:

1. Simple Table
2. Table with Header and Caption
3. Table with Colspan
4. Table with Rowspan
5. Table with an Image

**File:** `part-a.html`

### Part B: Formatting Web Page with Table

This section demonstrates how to create a basic webpage layout using an HTML table.

The layout includes a banner, navigation area, spacer, and main content area.

**File:** `part-b.html`

### Part C: HTML Forms and Input

This section demonstrates the implementation of an HTML form with different input elements, including:

- Text input
- Password input
- Radio buttons
- Dropdown menu
- Textarea
- Submit button

**File:** `part-c.html`

### Part D: Multiple HTML Pages

This section consists of four interconnected HTML pages.

| File | Description |
|---|---|
| `index.html` | Main homepage with navigation links |
| `personal.html` | Personal information, introduction, and profile picture |
| `table.html` | Favourite food table with headers and caption |
| `university.html` | Introduction to UMPSA and its official website |

The pages are connected using HTML hyperlinks to allow navigation between them.

- GitHub

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder using Visual Studio Code.
3. Place the project folder inside `C:\xampp\htdocs`.
4. Start Apache using the XAMPP Control Panel.
5. Open a web browser and visit:

   `http://localhost/lab-exercise-2-2/`

6. Use the navigation links on the homepage to explore the different pages.

Alternatively, individual HTML files can be opened directly in a web browser without XAMPP.
